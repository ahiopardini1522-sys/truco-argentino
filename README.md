# Truco argentino

App Android con dos partes: jugar al truco contra la compu (envido, real envido, falta envido, truco, retruco, vale cuatro; sin flor) y un anotador de truco con fósforos.

Cada vez que se sube un cambio a `main`, GitHub Actions compila el APK y lo deja en **Releases** como `Truco.apk`.
